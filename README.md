# Family Finance

Hệ thống quản lý tài chính gia đình cho Cục Thịt và Cục Cá.

- Tài liệu dự án (đặc tả, kế hoạch, quyết định): lưu ở thư mục `02_Project_Documents` trên máy, không đưa vào repo này.
- Trạng thái: giai đoạn 0 (nền tảng). Chưa có mã ứng dụng.
- Dữ liệu tài chính thật không được commit vào repo. Xem `.gitignore`.

## Biến môi trường

Xem `.env.example`. Không commit file `.env` hay `.env.local`.
